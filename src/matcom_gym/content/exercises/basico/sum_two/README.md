# Suma de dos números

## Enunciado

Implementa la función `sum_two(a, b)` que recibe dos enteros y devuelve su
suma.

## Firma

```python
def sum_two(a: int, b: int) -> int
```

## Consideraciones

- Los argumentos pueden ser **positivos**, **negativos** o **cero**.
- El resultado también es un entero.
- Python maneja enteros arbitrariamente grandes de forma nativa, no te
  preocupes por el desbordamiento.

## Ejemplos

```
sum_two(2, 3)     →  5
sum_two(0, 5)     →  5
sum_two(-3, -4)   →  -7
sum_two(-5, 5)    →  0
```

## Cómo trabajar

1. Editá `solution.py`.
2. Corré `python solution.py` para ver los ejemplos visibles.
3. Cuando creas que está listo: `matcom-gym evaluar sum_two`.

Si te trabás, podés ver la solución canónica:
`matcom-gym peek sum_two`.
